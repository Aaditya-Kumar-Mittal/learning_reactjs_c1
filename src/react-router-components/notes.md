# React Router Notes

- Browser Router is a component that enables routing in a React application. It uses the HTML5 history API to keep the UI in sync with the URL. When you wrap your application with BrowserRouter, it allows you to define routes and navigate between different components based on the URL.
- Client Side Routing refers to the process of handling routing on the client side, rather than making requests to the server for each route change. In a React application, client-side routing is typically implemented using libraries like React Router. This allows for a smoother user experience, as it avoids full page reloads and enables dynamic content updates based on the current route.
- Routes are used to define the mapping between a URL path and a specific component that should be rendered when that path is accessed. - Link is a component provided by React Router that allows you to create navigation links within your application. It is used to navigate between different routes without triggering a full page reload. The `<Link>` component takes a `to` prop, which specifies the target URL or route to navigate to. When a user clicks on a `<Link>`, React Router updates the URL and renders the corresponding component associated with that route.
